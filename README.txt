SITE: PERSONALIZADOS MÃE DO AMOR

Conteúdo
- index.html: site responsivo de apresentação e catálogo demonstrativo.
- CNAME: domínio personalizado (personalizadosmaedoamor.com.br).

ANTES DE PUBLICAR
1. Abra index.html num editor de texto.
2. Procure por: const WHATSAPP_NUMBER = "5511999999999";
3. Substitua pelo WhatsApp comercial correto, com 55 + DDD + número, somente dígitos.
4. Troque as ilustrações demonstrativas por fotos reais dos produtos e revise textos, preços, prazos e condições.

PUBLICAÇÃO GRATUITA (UMA OPÇÃO: GITHUB PAGES)
1. Crie/acesse uma conta no GitHub.
2. Crie um repositório público, por exemplo: personalizados-mae-do-amor.
3. Envie index.html e CNAME para a raiz do repositório.
4. Em Settings > Pages, escolha publicar a partir da branch principal (main), pasta /(root).
5. Em Settings > Pages > Custom domain, configure personalizadosmaedoamor.com.br, caso não seja preenchido automaticamente pelo arquivo CNAME.
6. Só depois de configurar o domínio nas configurações do GitHub Pages, abra o painel DNS do Registro.br e crie os registros indicados na documentação oficial do GitHub para domínio raiz e www.
7. Não apague registros existentes de e-mail ou outros serviços. Se já houver registros DNS configurados, confira-os antes de alterar qualquer coisa.
8. Ative Enforce HTTPS quando essa opção estiver disponível. A propagação de DNS e emissão do certificado podem levar algum tempo.

Documentação oficial do GitHub Pages:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site

OBSERVAÇÃO
Este pacote contém os arquivos do site, mas não publica automaticamente o site na internet nem altera o Registro.br. A publicação e a configuração do domínio exigem acesso à conta de hospedagem e ao painel DNS do titular.
